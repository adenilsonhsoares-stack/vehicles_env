# vehicles_env

Projeto desenvolvido durante o Sprint 5 do curso de Análise de Dados da TripleTen.

## Descrição do projeto

O objetivo deste projeto é criar um aplicativo web para visualizar dados de anúncios de vendas de carros.

O aplicativo foi desenvolvido utilizando Python, Pandas, Plotly Express e Streamlit.

## Funcionalidades

O aplicativo permite:

- Criar um histograma para visualizar a distribuição da quilometragem dos veículos.
- Criar um gráfico de dispersão para visualizar a relação entre a quilometragem e o preço dos carros.

Os gráficos são interativos e podem ser visualizados diretamente no navegador.

## Tecnologias utilizadas

- Python
- Pandas
- Plotly Express
- Streamlit
- Jupyter Notebook

## Como executar o projeto

1. Instale as bibliotecas necessárias:

   ```bash
   pip install -r requirements.txt
   ```

2. Execute o aplicativo:

   ```bash
   streamlit run app.py
   ```
